# CLAUDE.md

This repository is a training project. The full brief and agent rules are in `document.md`.

At the start of every session:

1. Read `docs/learning/progress.md` to see where the owner left off and which exercise is open.
2. Follow `document.md`, especially §28 (golden path vs challenge path) and §30: do not solve
   owner exercises unless the owner explicitly asks for help.

At the end of every session (or when the owner asks), update `docs/learning/progress.md`:
current status, a new session-log entry, decisions, lessons, and open exercises.

Repository artifacts are written in English (§31).

Windows note: when running `docker exec` with absolute container paths from Git Bash,
prefix the command with `MSYS_NO_PATHCONV=1`.
